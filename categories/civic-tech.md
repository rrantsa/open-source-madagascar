# Civic Tech

This category will list open source projects that help communities report issues, coordinate locally, access public information, or improve civic participation in Madagascar.

## Included Projects

### VeriSphere

- Repository: https://github.com/Hernat/VeriSphere
- Description: Android floating bubble app that verifies social-media posts through Gemini in one long-press and expands into a source-backed detail panel.
- Category: civic-tech
- Language: Kotlin
- Framework: Android, Jetpack Compose, and Gemini API
- License: MIT
- Status: experimental
- Maintainer: Hernat
- Target users: Android users, journalists, students, civic-tech contributors
- Madagascar relevance: An Android-first fact-checking tool can help Malagasy users, journalists, and community organizations assess viral social-media claims more quickly in a mobile-first information environment.
- Notes: The repository has a clear MIT license and visible activity on 2026-05-20. The README explicitly labels the app as a pre-V1 alpha at version `0.1.0`, with no signed APK published yet, so `experimental` is the safest catalogue status.

### Passeport Madagascar Paris

- Repository: https://github.com/Harrylepap/suivi-passeport-mg
- Description: Telegram bot that tells Malagasy citizens in France when their passport is ready for collection at the Embassy in Paris, by reading the embassy's image-based lists with OCR.
- Category: civic-tech
- Additional categories: public-services
- Language: Python, JavaScript
- Framework: Cloudflare Workers, GitHub Actions, and Tesseract OCR
- License: MIT
- Status: active
- Maintainer: Harrylepap
- Target users: Malagasy citizens in France, Malagasy diaspora
- Madagascar relevance: The Embassy of Madagascar in France announces ready passports only as images of receipt-number tables, with no search or notification. The bot indexes these lists, answers by receipt number, and notifies people when their number appears.
- Notes: GitHub shows a public MIT license and continuous activity since 2026-11-25, with automated tests and releases. Unofficial volunteer service, not affiliated with the Embassy of Madagascar in France. The repository contains no personal data; user data handling is documented in a public GDPR processing register.
